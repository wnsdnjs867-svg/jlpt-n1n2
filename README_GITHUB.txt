JLPT 단어장 GitHub Pages 배포 방법

1. GitHub에서 새 저장소를 만듭니다. 저장소는 Public으로 설정합니다.
2. 이 ZIP의 압축을 풉니다.
3. 압축을 푼 폴더 안의 파일을 전부 저장소 최상단에 업로드합니다.
   index.html, app.js, words.js, style.css가 저장소 첫 화면에 보여야 합니다.
4. 저장소의 Settings → Pages로 들어갑니다.
5. Build and deployment에서 Source를 Deploy from a branch로 선택합니다.
6. Branch를 main, 폴더를 /(root)로 선택하고 Save를 누릅니다.
7. 잠시 후 같은 화면에 표시되는 주소로 접속합니다.

주의: 기존 사이트에서 저장한 회독·복습 기록은 새 GitHub 주소로 자동 이전되지 않습니다.
